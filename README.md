## 🧾 Project 1: Smart Bill Splitter & Tip Calculator
A CLI (Command Line Interface) utility application designed to calculate total restaurant bills with dynamically adjusted tip structures and equal user distribution metrics.

### 💡 Core Features & Implementations
* **Dynamic Arithmetic Operations:** Automates tax, percentage, and grand total calculations.
* **Robust Input Validation:** Utilizes `try-except` exception handling blocks to manage malformed user input data gracefully and prevent runtime crashes.
* **Precision Formatting:** Employs precise float precision constraints (`:.2f`) to cleanly map financial transactions.

### 🛠️ Technical Stack
* **Language:** Python 3.x
* **Core Logic:** Conditional blocks, exception handling, string interpolation

### 🚀 How To Run
1. Ensure Python is installed on your local environment.
2. Clone this repository or download `bill_splitter.py`.
3. Open your terminal, navigate to the folder, and run:
   ```bash
   python bill_splitter.py
   ```
